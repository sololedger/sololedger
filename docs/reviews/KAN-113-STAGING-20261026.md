## Verktygsavvikelser och avgränsning

- Vercel MCP nekade läsåtkomst (403). Den redan etablerade, explicit team-/projekt-
  avgränsade CLI-vägen fungerade; ingen ny inloggning eller inställningsändring.
- Aliasverktygets första metadatajämförelse behövde samma JSON-normalisering
  som tidigare verktyg (undefined-fält kontra sparad JSON). Faktiska metadata
  var oförändrade. Ingen migrations- eller produktanpassning gjordes.
- Hosted testverktyget korrigerades för React-knappens avstängda semantik,
  årsväljarens stegvisa alternativ och serverbekräftat asynkront checklistesparande.
  Före omtest avstämdes faktiskt syntetiskt tillstånd; tidigare lyckade lås
  återanvändes som läsfall med separat sparat UI→RPC-kvitto. Inga kontroller i
  produkten försvagades, inga nya produktcommits publicerades.
- Kalendergränsens ±1ms-prov gjordes lokalt; serverklockan i hosted Staging har
  inte manipulerats. Ingen ombyggnad för brutna/förlängda räkenskapsår ingick.
